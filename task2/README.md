Лабораторная работа №2. Адаптивная вёрстка

Сделано: одностраничный лендинг кемпинга «Камчатка» с использованием CSS Grid для крупной сетки страницы и Flexbox для компонентов (шапка, форма, футер). Вёрстка выполнена по подходу Mobile First с медиазапросами под три контрольные точки: мобильный (до 767px), планшет (768–1199px), десктоп (от 1200px). На мобильной ширине навигация скрыта в гамбургер. Добавлена форма обратной связи с полями «Имя», «Email», «Сообщение» и кнопкой «Отправить». Без JavaScript.
